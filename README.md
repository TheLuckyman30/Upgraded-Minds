# Upgraded Minds

A simple Stellaris mod that allows organinc empires to follow the machine age acesnion paths.

- Adds an acension perk called Upgraded Minds that will convert your **main** species into a machine species.
- After conversion, the transformation situation will begin as if you took the Synthetic Age acension perk.

Note: **DO NOT** take the synthetic age acesion perk after you species has been converted. It won't break anything, but it will take up an extra acension perk slot for no reason. The Upgraded Minds acesnion perk will already bring you down the machine acesion paths.
